# AD Car: versões

Launcher da central multimídia do Jeep Renegade (Aikon Atom, Android 8.1).

- **AD-Car.apk**: versão mais nova para a central (2.0.0).
- **AD-Car-Ponte.apk**: app do celular que leva o OBD2 para a central pelo Wi-Fi.

A central procura atualizações sozinha em Ajustes › Atualizações (lê `latest.json`).
